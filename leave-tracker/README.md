# Leave Tracker

A small leave-request app.
- server/ — REST API: Node.js, Express, TypeScript, SQLite
- client/ — web app: React, TypeScript, Vite

Requires Node.js 16.20 or newer.

## Run locally
1. Install the dependencies of both apps.
2. Server: create your .env from .env.example, then set up the database before the first start.
3. Start the API, then start the client and open the URL it prints.

## Tests
Server tests: npm test (inside server/).
